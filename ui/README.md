# Demo UI (Gradio)

A viewer for the jury: load a phone photo and the packshot our pipeline produced, drag the gold
divider to reveal one over the other, and hover to magnify details (logos, buttons, weave).
The UI does **not** call the model; it displays pictures generated by `pipeline.py`.

```bash
pip install gradio pillow
python ui/interface_single.py      # one garment
python ui/interface_double.py      # two garments side by side
```
Open the printed local URL in a browser. Pictures to load: `submissions/aactivetion_function/<gid>/front.png`
and the matching phone photo.
